# Searching and Sorting

Practice programs for common array searching, sorting, and rearrangement techniques.

## Programs

| File | Topic |
| --- | --- |
| `bubble_sort.cpp` | Bubble sort |
| `selection_sort.cpp` | Selection sort using `min_element` |
| `selection_sort_v2.cpp` | Selection sort with manual index tracking |
| `move_zeros.cpp` | Move all zeros to the end while preserving order |

## Compile and run

From this directory:

```powershell
g++ move_zeros.cpp -o move_zeros.exe
.\move_zeros.exe
```

Replace `move_zeros` with the program name you want to run.
