## Why This Repo

This repository is my daily C++ practice space.
The goal is simple: solve core programming problems consistently and build problem-solving speed.

## Learning Tracks

### 1) Number Logic
- Fibonacci series
- Prime number
- Reverse / palindrome / Armstrong numbers
- Perfect / strong / automorphic numbers
- Leap year and number classification

### 2) Pattern Printing
- Square, triangle, pyramid, diamond, butterfly
- Hollow and aligned pattern variants

### 3) Functions
- Reusable logic with function-based problems
- Prime check, factorial, Fibonacci, calculator

### 4) Arrays
- Input/output, sum, min/max
- Search, frequency, duplicates
- Reverse, rotation, sorting
- Two Sum

## Quick Start

### Compile
```bash
g++ 65_Two_Sum.cpp -o 65_Two_Sum
```

### Run
```bash
./65_Two_Sum
```

On Windows PowerShell:
```powershell
.\65_Two_Sum.exe
```
